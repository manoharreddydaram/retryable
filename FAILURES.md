# What broke, and how we got out

A running log, written on the day each problem occurred rather than
reconstructed afterwards. Each entry names the commit that fixed it.

The Razorpay submission form asks: *"What issues did you face while building,
and how did you solve them?"* This file is the answer, and it is kept honestly.
Entries include problems that were our own fault.

---

## Format

```
### F-00N — Short title
**Date:**
**Stage:**
**What broke:**
**Why it broke:**
**How we detected it:**
**The fix:**
**Commit:**
**What we learned:**
```
